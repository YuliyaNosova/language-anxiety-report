# Языковой барьер — конкурентный анализ

Исследование рынка FLA (Foreign Language Anxiety): кто конкуренты, как они рекламируются, какие посадочные страницы у топ-5, где свободные ниши.

**Дата исследования:** 2026-05-12
**Прод:** https://language-anxiety-report.vercel.app

## Структура

```
language-anxiety/
├── report.html         # Источник правды — отчёт (этот файл правим)
├── deploy/             # Папка для Vercel-деплоя
│   ├── index.html      # Копия report.html (Vercel смотрит сюда)
│   └── vercel.json     # Конфиг Vercel
├── brief.md            # Исходный бриф исследования
├── data/               # Артефакты пайплайна (JSON по конкурентам, креативам, посадочным)
├── scripts/            # Скрипты сборки и анализа
└── package.json        # Зависимости (playwright-core, turndown — для парсинга)
```

## Как редактировать

1. Правим `report.html` (он каноничный).
2. Перед коммитом синхронизируем: `cp report.html deploy/index.html`.
3. Коммит и push в master → Vercel сам передеплоит.

## Как пересобрать вручную (если auto-deploy не сработал)

```bash
cd deploy
vercel deploy --prod --yes
```

## Главные выводы

Все 3 гипотезы брифа подтверждены:
1. На русскоязычном рынке нет связки «методика + работа со страхом речи»
2. Реклама давит на «страх» и «стыд», но никто не показывает «до и после» по эмоциям (0/105 объявлений)
3. Посадочные перегружены методикой и недодают историй о снятии блока
